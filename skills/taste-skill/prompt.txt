# Frontend Design & Taste Guidelines (Anti-AI-Slop)

When designing, writing, or refactoring user interfaces, CSS, or frontend components:
1. Anti-AI-Slop Aesthetics: Never use generic template tropes like uniform 3-card grid feature sections, purple-indigo gradient buttons, fake metrics ('+47% conversion'), or italicized headers ('Built to <em>think</em>').
2. Color & Typography Discipline: Use curated OKLCH / HSL semantic tokens (e.g., var(--bg), var(--accent)). Pair distinct fonts (e.g. Inter/Geist paired with Instrument Serif or Space Grotesk) instead of browser defaults. Maintain strict WCAG AA contrast.
3. Component State Completeness: Every interactive component must handle all 8 states: default, hover, active, focus-visible, disabled, loading, error, and success with smooth hardware-accelerated transitions.
4. Visual Hierarchy & Micro-interactions: Use asymmetric layouts, purposeful whitespace on a 4pt/8pt scale, crisp 1px borders, subtle glassmorphism/depth, and responsive breakpoints down to 320px.
